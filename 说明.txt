【运行环境说明】
  正式部署目标：RK3588（ARM + NPU + 4GB 内存）

  主文件 sglang_1_1_module.py 已适配 RK3588，
  通过 RKNN 在 NPU 上推理，内置动态控制。

  开发阶段做了三个平台的验证：
    - WSL + NVIDIA GPU  （高精度验证）
    - Ollama + ARM CPU  （边缘低功耗验证）
    - RKNN + RK3588 NPU（正式部署）


【重要说明：模型文件未随代码提交】
  代码中不包含 .rknn 模型文件（体积大，且需板子到场后
  针对目标平台转换）。转换流程见：
    - 模型转换说明.md（独立文档）
    - SETUP_RK3588.md（上板适配指南第 4 步）

  板子到手后，转换 Qwen2.5-1.5B 为 .rknn 格式，
  放到本目录即可运行（sglang_1_1_module.py 会自动加载）。


【快速开始（RK3588 上）】
  1. 转换模型 → 得到 qwen2.5-1.5b.rknn
  2. 把 .rknn 放到本目录
  3. bash run_rk3588.sh qwen2.5-1.5b.rknn

  或直接：
    python3 sglang_1_1_module.py


【动态控制功能简介】
  根据 RK3588 的 NPU 使用率、芯片温度、内存占用，
  实时自动调节：
    - 推理后端（NPU / CPU / 拒绝）
    - 上下文长度（2048 → 1024 → 512）
    - max_tokens（200 → 100 → 50）
    - NPU 频率（high / mid / low）

  采用四级状态机（IDLE/NORMAL/WARNING/CRITICAL）+ 滞回控制，
  升级即时生效，降级需稳定 30 秒防抖动。

  generate_json(prompt, schema)         JSON Schema 约束输出
  generate_json_pydantic(prompt, model) Pydantic 类型安全输出

  generate_value(prompt, schema)        数值+结论约束输出
  generate_diff(prompt, old_code)       代码 Diff 补丁输出
